# 205 - ML & AI Projects

Learning journey from classical ML to LLM agents. Each project builds on the previous one.

## Learning path

| # | Project | Tech | Status |
|---|---------|------|--------|
| 205.01 | [Flight Price Predictor](./205.01-flight-price-predictor) | scikit-learn, Streamlit | ✅ Step 1 |
| 205.02 | Document Chatbot | Hugging Face, ChromaDB | 🔜 Step 2 |
| 205.03 | Autonomous Agent | LangChain, Ollama | 🔜 Step 3 |

## Stack
- Python 3.10+
- scikit-learn · pandas · numpy
- Hugging Face Transformers
- LangChain · ChromaDB · Ollama
- Streamlit

## Why this order?
1. **Classical ML** — understand supervised learning, features, evaluation metrics. No black boxes.
2. **LLMs + RAG** — learn how to ground language models in your own documents.
3. **Agents** — combine tools + reasoning so the model acts autonomously.
